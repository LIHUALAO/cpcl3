# 需要主人真人验证的清单

> 这些是我在无头/远程环境里**无法自己验证**的，必须真人操作。
> 每条都写清了「怎么做」「看什么」「正常应该是什么样」。

---

## A. 首次真实启动（最高优先级）

**为什么我做不了**：我这边是无头环境，SDL 创建不了窗口，游戏只在渲染线程启动后就被我杀掉。

**怎么做**

```powershell
cd C:\Users\Administrator\Desktop\DSW\PCL3
C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe dist\cli\index.js web
```

浏览器打开 `http://127.0.0.1:37421` → 装 `26.3` → 点「启动」。

**要看什么**

| 检查点 | 正常表现 |
|---|---|
| 游戏窗口 | 真的弹出一个 Minecraft 窗口，不是一闪而过 |
| 主界面语言 | **中文**（「单人游戏」「多人游戏」「设置」） |
| 窗口标题 | `Minecraft 26.3` |
| 能否进单人游戏 | 点进去能创建世界 |

**如果失败**：把 `%APPDATA%\PCL3\instances\<版本>\logs\latest.log` 发给我，或告诉我最后一行是什么。

## B. Fabric 模组真的生效

**为什么我做不了**：需要真实装一个 mod 并进游戏看模组列表。

**怎么做**
1. 点 26.3 卡片的「装模组加载器」→ Fabric → 确认
2. 装完后点「内容」→ 搜 `sodium` → 装到那个 Fabric 实例
3. 启动 Fabric 版本
4. 游戏主界面 → 模组列表（Mods）

**要看什么**：模组列表里出现 **Sodium**（或你装的 mod），而且游戏没崩。

---

## C. 中文界面是否真的生效

**怎么做**：删掉 `%APPDATA%\PCL3\instances\26.3\options.txt`，然后启动。

**要看什么**：游戏界面是中文。如果还是英文，说明 `options.txt` 的 `lang:zh_cn` 没被游戏认可。

---

## D. 打开文件夹

**怎么做**：版本卡片 → 「📂 打开文件夹」→ 点「mods」。

**要看什么**：资源管理器弹出并定位到 `...\instances\26.3\mods`。**只弹一次**（之前测试会反复弹，已修）。

---

## E. 崩溃分析是否说人话

**怎么做**：故意制造一个崩溃——比如把 `<实例>\mods\` 里放一个明显不兼容的 mod，或把 `-Xmx` 调到 512 启动大型整合包。

**要看什么**：任务面板显示的是「内存不足，建议调到 XXXX」这类人话，不是一堆 `java.lang.OutOfMemoryError` 堆栈。

---

## F. 整合包导入

**怎么做**：从 Modrinth 下载一个 `.mrpack`（比如 [Sodium 整合包]），点「导入整合包」→ 选文件。

**要看什么**
1. 先显示**解析结果**（包名、MC 版本、加载器、mod 数、大小）
2. 确认后才安装
3. 装完出现一个新实例，可直接启动

---

## G. 卡顿与性能

**怎么做**：正常用 10 分钟——滚动版本列表、搜索 mod、开关页面。

**要看什么**：滚动流畅、切页面不卡。如果某个操作明显卡顿（>1 秒），告诉我是哪个。

## 已知的非阻塞项（不用管）

- 日志里的 `Failed to fetch user properties: 401` —— 离线账户的正常现象

- Java 版本提示「未安装」但实际上已下载 —— 那是检测显示问题，不影响启动
