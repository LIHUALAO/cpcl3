# PCL3 对标 PCL2 差距清单（Lead 自用）

目标：让 PCL3 像 PCL2 一样好用。允许增删功能，整晚迭代。

## 一、PCL2 做得好的地方（用户真正会感知到）

### 1. 启动前自动体检
PCL2 点「启动」前会检查：Java 版本对不对、内存够不够、mod 有没有冲突、文件完不完整。
**不满足就直接给结论 + 一键修复**，而不是让游戏崩了再回来问。

### 2. 崩溃后能说人话
「你的 XX mod 需要 Fabric API」「内存给太小了，建议 4096」——不是甩一堆堆栈。
**而且它能一键把有问题的 mod 挪走。**

### 3. 下载速度可见可控
显示实时速度、剩余时间、当前文件。慢的时候能换源。

### 4. 版本/实例列表信息密度高
一张卡片能看到：版本、加载器、mod 数、上次玩的时间、大小、是否可玩。

### 5. 一次点击能做完的事
- 点版本 → 直接玩（缺 Java 自动装、缺库自动下）
- 拖一个 mod 进窗口 → 自动装到当前实例
- 拖一个整合包 → 自动建实例
- 拖一个 `.jar` → 判断是 mod 还是整合包还是光影

### 6. 设置项分组清晰
游戏设置 / 启动设置 / Java 设置 / 下载设置 / 界面设置，每一项都有说明。

### 7. 键盘友好
回车启动、ESC 关闭弹窗、方向键选择。
